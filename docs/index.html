System Architecture

End-to-End Intelligence Pipeline

Deterministic ingestion, zero-allocation caching, and structured inference without single points of failure.

1

Ingest & Guard

Asynchronous HTTP clients with exponential retry strategies. Includes internal SSRF validation (assert_safe_remote_url) blocking private IP spaces and metadata endpoints.

2

Deduplicate & Reason

Local SQLite database operating in WAL mode stores statement SHA-256 digests. Evaluates monetary stance via structured Pydantic schemas with automatic rule-based fallback when offline.

3

Render & Dispatch

Generates yield curve charts using headless Matplotlib (Agg), compiles executive Markdown briefs, renders Rich terminal tables, and pushes HTML-escaped Telegram notifications.

CLI & Automation

Command Line Interface

Built with Typer and Rich for fluid local inspection and headless background execution.

$ macro-sentinel scan --now

Executes an immediate end-to-end macroeconomic intelligence scan, generates Markdown report, plots yield curve, and renders full Rich terminal dashboard.

$ macro-sentinel daemon

Starts the APScheduler background daemon in the foreground, executing scans periodically according to SCAN_CRON_SCHEDULE.

$ macro-sentinel list-series

Outputs formatted tables of all registered FRED time series IDs, calculation units, and central bank RSS/Atom endpoints.

$ macro-sentinel test-apis

Verifies live external network connectivity to the St. Louis Fed API and Central Bank RSS feeds with immediate pass/fail output.
